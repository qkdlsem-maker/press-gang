# Press Gang 2.0.1-beta.1 · 무료 공개 베타 / Free public beta

**“파일이 너무 큽니다.” 그 말, 그만 듣죠.**

사진을 붙여넣고 목표 용량을 고르면 압축반장이 용량을 정리합니다. 전후 비교 후 파일로 복사하거나 저장하세요. 원본은 수정하지 않습니다.

- **한국어 / 영어 전환**: 화면·상태·오류·도움말·저장 창·탐색기 메뉴까지 지원합니다. 목록과 결과는 유지합니다.
- **붙여넣고 바로 압축**, 결과 파일 복사, 여러 파일 처리, 선택한 한 장 재압축.
- 선택 기능인 탐색기 메뉴로 사진 한 장을 **500 KB / 1 MB** 목표로 압축·저장.
- 목표를 못 맞추면 초과 표시. 로컬 처리이며 파일 업로드·계정·광고 없음.

**설치:** Assets에서 `PressGang-Setup-2.0.1-beta.1-x64.exe`를 받으세요. `Source code`는 설치 파일이 아닙니다. Windows x64용이며 Windows 11에서 검증했습니다. [한국어 설치 안내](https://github.com/qkdlsem-maker/press-gang/blob/main/docs/INSTALL.ko.md).

**시연:** `PressGang-Demo-ko.mp4`, `PressGang-Demo-en.mp4`는 실제 앱 녹화입니다. 압축률은 이미지와 설정에 따라 달라집니다.

**베타 안내:** 무료이며 설치 파일은 아직 서명되지 않았습니다. Windows에서 알 수 없는 게시자나 평판 경고가 나올 수 있습니다. 보안 기능을 끄지 마세요. `SHA256SUMS.txt`로 공개 파일과 일치하는지 확인할 수 있습니다. PDF·영상·애니메이션·PNG 출력은 미지원입니다. 손실 압축으로 화질이나 해상도가 낮아질 수 있습니다.

**“File too large.” We can have a word with it.**

Paste an image, choose a file-size limit, compare the result and copy or save the compressed file. Your original walks out unharmed.

- **Switch between English and Korean**, including messages, help, native dialogs and Explorer menu labels. Your queue and results stay in place.
- Paste-and-compress, file clipboard output, batch processing and selected-image recompression.
- Optional Explorer menu for **500 KB / 1 MB** jobs.
- Honest over-limit feedback. Local processing with no uploads, accounts or ads.

**Install:** Download `PressGang-Setup-2.0.1-beta.1-x64.exe` from Assets. “Source code” is not the installer. Windows x64; tested on Windows 11. [English installation guide](https://github.com/qkdlsem-maker/press-gang/blob/main/docs/INSTALL.en.md).

**Watch:** The English and Korean MP4 files are real app recordings using the included illustration. Results vary by image and settings.

**Beta limits:** The installer is unsigned and may trigger Windows publisher/reputation warnings. Do not disable security features. Compare the download with `SHA256SUMS.txt`. PDFs, video, animation and PNG output are unsupported. Lossy compression may reduce quality or dimensions. The beta is free to use; original source remains `UNLICENSED`, with no new general reuse license. Third-party licenses are included.
