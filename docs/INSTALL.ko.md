# 압축깡패 2.0.1-beta.1 설치 안내

[English](INSTALL.en.md)

## 다운로드와 설치

Windows 11 x64에서 검증했습니다. macOS·Linux·Windows ARM64 전용 설치 파일은 없으며 Windows 10은 이번 베타에서 검증하지 않았습니다.

[공식 릴리스](https://github.com/qkdlsem-maker/press-gang/releases/tag/v2.0.1-beta.1)에서 `PressGang-Setup-2.0.1-beta.1-x64.exe`를 받으세요. 한국어 또는 영어를 골라 현재 Windows 사용자에게 설치하며 관리자 권한을 요구하지 않습니다. 시작 메뉴에는 **압축깡패**, 실행 파일 이름은 `PressGang.exe`로 표시됩니다.

현재 설치 파일은 서명되지 않았습니다. Windows에서 알 수 없는 게시자 또는 평판 경고가 나올 수 있습니다. 보안 기능을 끄지 마세요. 판단하기 어려우면 설치를 멈추고 개인 정보를 가린 경고 내용을 제보해주세요.

다운로드한 폴더에서 PowerShell을 열어 아래 값을 릴리스의 `SHA256SUMS.txt`와 비교할 수 있습니다.

```powershell
Get-FileHash -Algorithm SHA256 .\PressGang-Setup-2.0.1-beta.1-x64.exe
```

해시 일치는 공개한 파일과 동일하다는 뜻이며 코드 서명 인증서를 대신하지는 않습니다.

## 처음 실행과 언어

앱 상단에서 **한국어 / English**를 고르세요. 정지 JPG·PNG·WebP를 추가하고 목표 용량을 정한 뒤 압축·비교·복사 또는 저장하면 됩니다. 언어 선택은 다음 실행에도 유지됩니다. 언어를 바꿔도 목록과 결과는 유지되며 작업 중에는 언어 선택이 잠시 비활성화됩니다.

**빠른 작업 → 탐색기 우클릭 메뉴**는 선택 기능이며 기본으로 꺼져 있습니다. 현재 사용자에게만 등록합니다. Windows 11에서는 **더 많은 옵션 표시**에서 찾으세요. 앱에서 끄면 해당 메뉴를 제거합니다. 영어에서는 영어 메뉴를 등록하고 앱 언어를 바꾸면 켜져 있는 메뉴도 바뀝니다.

## 파일 저장 위치

- **결과 저장**은 폴더를 직접 고릅니다.
- **파일 복사**, 결과 끌어내기, 탐색기 빠른 압축은 **다운로드 → 압축깡패**에 보관합니다. 두 언어에서 같은 폴더를 씁니다.
- 한국어 결과는 `-압축`, 영어 결과는 `-compressed`를 붙입니다. 같은 이름이 있으면 번호를 붙이며 기존 파일을 덮어쓰지 않습니다.
- 자동 모드에서 이미 목표 이하인 파일은 원래 형식과 메타데이터를 유지할 수 있습니다.
- 접수대 비우기는 저장한 파일을 지우지 않습니다. 임시 복사본은 정상 종료 시 삭제하며 비정상 종료 시 Windows 임시 폴더에 남을 수 있습니다.

## 업데이트와 삭제

자동 업데이트는 없습니다. 필요한 결과를 저장하고 앱을 닫은 뒤 새 공식 설치 파일을 실행하세요. 다른 경로를 고르지 않으면 기존 2.0.0과 같은 사용자별 위치를 사용합니다. 미저장 결과는 앱 재시작 후 유지되지 않습니다.

**Windows 설정 → 앱 → 설치된 앱 → 압축깡패**에서 삭제할 수 있습니다. 앱의 탐색기 메뉴도 제거됩니다. 내보낸 사진은 저장 폴더에 남고 환경설정은 앱의 사용자 데이터 폴더에 남을 수 있습니다. 필요 없을 때만 직접 삭제하세요.

## 문제가 생겼다면

[한국어·영어 제보 양식](https://github.com/qkdlsem-maker/press-gang/issues/new/choose)을 이용하세요. 붙여넣기 문제는 상대 앱 이름과 저장한 파일을 직접 첨부하면 되는지도 알려주세요. 원본 사진은 필수가 아닙니다. 개인 사진·비밀번호·가리지 않은 개인 경로는 올리지 마세요.
