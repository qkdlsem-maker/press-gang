압축깡패 2.0.1-beta.1

파일만 손댑니다.

JPG·PNG·WebP 정지 이미지를 목표 용량에 맞춰 압축합니다. 한 장당 최대 100MB·8천만 픽셀, 한 번에 12장·총 350MB까지 받습니다.

자동 선택은 일반 사진을 JPG로, 투명 이미지를 WebP로 만듭니다. JPG를 직접 선택하면 투명한 부분은 흰색이 됩니다. PNG 출력과 PDF·영상 압축은 지원하지 않습니다.

목표보다 작은 파일은 자동 선택에서 원본 그대로 돌려줍니다. 압축 시 화질이나 해상도가 낮아질 수 있으며, 조건 내에서 목표를 달성하지 못하면 표시합니다. 1MB = 1,000,000바이트입니다.

원본은 수정하지 않습니다. 결과는 선택한 폴더에 새 이름으로 저장하며 기존 파일을 덮어쓰지 않습니다. 파일 복사·끌어내기·탐색기 빠른 압축 결과는 다운로드 폴더 안의 압축깡패에 보관합니다. 접수대 비우기는 저장한 결과를 지우지 않습니다. 그 외 임시 복사본은 정상 종료 시 삭제됩니다. 비정상 종료 시 Windows 임시 폴더에 남을 수 있습니다.

클립보드는 붙여넣기를 요청할 때만 읽습니다. 파일 업로드·계정·추적·광고·자동 실행이 없습니다. 압축 작업 중 인터넷에 연결하지 않습니다. 모든 접수 파일에 같은 목표가 각각 적용됩니다.

사진 파일이나 스크린샷을 복사하고 Ctrl V.

02

결과를 비교하고 Ctrl ⇧ C.
파일 붙여넣기를 지원하는 앱에서 Ctrl V 하세요.
03
